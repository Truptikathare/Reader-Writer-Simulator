Synchronization Rules

  • Multiple readers can access shared data simultaneously.
  • Only one writer can access the resource at a time.
  • Readers cannot read while a writer is writing.
  • A writer must wait until all active readers finish.
  • Requests are handled fairly using a FIFO queue.
